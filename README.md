# mood

Дневник эмоций: книга Excel для ручного ведения и Telegram-бот, который
разбирает свободное описание состояния.

## Telegram-бот

Пользователь пишет свободным текстом, что чувствует, что произошло и как это
отзывается в теле. Бот возвращает структурированный разбор: что видно в
описании, насколько это требует внимания, что можно сделать.

**Бот не ставит диагнозов** и не заменяет врача или психолога. Сообщения с
признаками угрозы жизни или здоровью распознаются детерминированно — до
обращения к модели — и получают ответ с контактами экстренных служб вместо
обычного разбора.

### Установка

```bash
python -m venv .venv
```

```bash
.venv/Scripts/python.exe -m pip install -e ".[dev]"
```

На Linux/macOS путь к интерпретатору — `.venv/bin/python`.

### Настройка

```bash
cp .env.example .env
```

Заполнить `.env`:

- `TELEGRAM_BOT_TOKEN` — обязательно, выдаёт [@BotFather](https://t.me/BotFather).
- `ANTHROPIC_API_KEY` — опционально. Без него бот работает на встроенном
  анализаторе по правилам: разбор проще, но бот отвечает и сохраняет записи.

Файл `.env` в `.gitignore`. Токены не должны попадать в репозиторий.

### Проверка конфигурации

```bash
.venv/Scripts/python.exe -m moodbot --check
```

Проверяет переменные окружения и выходит, не обращаясь к сети.

### Запуск

```bash
.venv/Scripts/python.exe -m moodbot
```

Long polling. Остановка — Ctrl+C.

### Команды бота

| Команда | Что делает |
|---------|-----------|
| `/start` | как пользоваться, дисклеймер |
| `/help` | список команд |
| `/history` | последние записи с их разбором |
| `/delete_me` | удалить все свои данные |

Любое другое текстовое сообщение читается как описание состояния.

### Данные

SQLite (`moodbot.sqlite3` по умолчанию), отдельно от `эмоции.xlsx`. Хранятся
текст записи, время и итог разбора. `/delete_me` удаляет всё по пользователю.

## Тесты

```bash
.venv/Scripts/python.exe -m pytest -q
```

С покрытием:

```bash
.venv/Scripts/python.exe -m pytest --cov=src/moodbot --cov-report=term-missing -q
```

Три слоя, от быстрых к медленным:

| Слой | Что покрывает |
|------|---------------|
| `tests/unit/` | модели и разбор ответа, конфиг, распознавание кризиса, анализатор по правилам, форматирование |
| `tests/mock/` | анализатор на фейковом Anthropic-клиенте (успех, таймаут, отказ, мусор), хендлеры на фейковых зависимостях |
| `tests/integration/` | SQLite на временном файле, сквозной путь «сообщение → разбор → запись → ответ», CLI |

Ни один тест не ходит в сеть и не требует настоящих ключей.

## Архитектура

```
src/moodbot/
  config.py        настройки из окружения, без секретов в repr
  models.py        Entry, Analysis, RiskLevel — и валидация ответа модели
  safety.py        детерминированное распознавание кризиса
  safety_texts.py  тексты кризисных ответов и дисклеймер
  service.py       порядок операций: сначала скрининг, потом анализ
  analyzer/        base (протокол), claude, fallback (правила)
  storage/         схема SQLite и репозиторий
  bot/             handlers (без фреймворка), formatting, telegram, app
```

Зависимости передаются внутрь, а не создаются на месте — поэтому каждый слой
тестируется без сети. Единственное место, знающее про aiogram, — `bot/telegram.py`;
единственное, собирающее граф объектов, — `bot/app.py`.
